# 🎭 Cinematic AI & Portfolio Platform

An interactive, high-performance web portfolio featuring smooth continuous scroll animations, modern bento grid layouts, and dynamic project showcases. Built with React, TypeScript, Framer Motion, and Tailwind CSS to highlight cutting-edge AI engineering, Computer Vision, and Generative AI projects.

## 🌟 Key Features

* **ScrollStack Architecture:** Smooth, interactive card-stacking mechanics driven by Framer Motion.
* **Bento Grid System:** Structured presentation highlighting core capabilities across Generative AI, Computer Vision, Full-Stack Architecture, and Machine Learning.
* **Dynamic Project Showcase:** Direct links and technical breakdowns of key repositories covering MediaPipe, YOLOv5, Ollama, DeepSeek, and Gemini API workflows.
* **Fully Responsive & Performant:** Optimized for high-FPS performance across desktop, tablet, and mobile views.

---

## 🛠️ Core Capabilities Showcase

* **Generative AI & Agentic Workflows:** Ollama local inference (DeepSeek R1, Gemma), Gemini API multimodal workflows, and dynamic prompt engineering.
* **Computer Vision & Real-Time Tracking:** 33-landmark pose estimation with MediaPipe, YOLOv5 object detection, and OpenCV manuscript region segmentation.
* **Machine Learning & Data Science:** Customer segmentation using K-Means clustering, PCA dimensionality reduction, and interactive dashboards.
* **Full Stack Integration:** Web application backends utilizing Node.js, Express, MongoDB Atlas, and modern React interfaces.
